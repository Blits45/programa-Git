1. ¿Qué es HTML5?

HTML es un lenguaje de marcado utilizado para estructurar el contenido de las páginas web. HTML5 utiliza elementos y etiquetas para organizar textos, imágenes, enlaces, formularios y otros contenidos.

2. Estructura básica de un documento HTML5

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi página</title>
</head>
<body>
    <h1>Hola mundo</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>

Partes principales

  • <!DOCTYPE html>: indica que se utiliza HTML5.
  • <html>: elemento principal del documento.
  • <head>: contiene información sobre la página.
  • <title>: título mostrado en la pestaña del navegador.
  • <body>: contiene el contenido visible.

3. Títulos y párrafos

Título principal: h1

Título secundario: h2

Subtítulo: h3

Subtítulo: h4

Subtítulo: h5
Subtítulo: h6

Este es un párrafo creado con la etiqueta <p>.

Podemos usar strong para indicar importancia y em para dar énfasis.

4. Enlaces

Los enlaces se crean con la etiqueta <a>:

<a href="https://developer.mozilla.org/">Visitar MDN</a>

Ejemplo: Aprender HTML en MDN

5. Imágenes

Para mostrar una imagen se utiliza la etiqueta <img>:

<img src="imagen.png" alt="Descripción de la imagen">

src indica la ubicación de la imagen y alt proporciona una descripción alternativa.

9. Elementos semánticos de HTML5

  • <header>: encabezado.
  • <nav>: navegación.
  • <main>: contenido principal.
  • <section>: sección temática.
  • <article>: contenido independiente.
  • <footer>: pie de página.
